# ☕ Swirlo – Backend (Node.js & Express API)

This repository contains the backend of Swirlo, responsible for authentication, business logic, payments, order management, and user order history.

---

## 🚀 Backend Features

* Google OAuth authentication
* Secure cookie-based authentication (HTTP-only cookies)
* Product & category management
* Orders, cart, and order history management
* Stripe payment processing
* Favorites management
* Email confirmation feature

---

## 🧰 Backend Tech Stack

* **Node.js**
* **Express.js**
* **MongoDB** (Mongoose)
